# 22 — Capstone: an explainable command system

The final project combines a DCG parser, structured requests, a knowledge base, inference, explanations and automated tests.

Build a command system for a small fictional world. Support at least three command types, ten domain facts, five inference rules, one recursive relation, a query with multiple answers, structured explanations, positive and negative tests, and documented example sessions.

Keep grammar, domain facts, inference, explanations, integration and tests separated.

The project must run inside the student OCI without private Ploos infrastructure. Document declarative parts, operational control, knowledge assumptions and implementation-specific dependencies.

# Exercises

These files are student workspaces corresponding to the numbered EduProlog modules.

They intentionally contain incomplete predicates and TODOs, so CI must **not** treat them as finished reference programs.

Suggested workflow:

1. Read the matching chapter in `course/no/` or `course/en/`.
2. Copy or edit the exercise file.
3. Test predicates interactively with SWI-Prolog.
4. Write additional tests of your own.
5. Compare with `solutions/` only after attempting the task.

The course examples in `examples/` are runnable reference examples. Exercises are for modification by the learner.
